# Task Tracker CLI

A command-line task manager that stores tasks in a local JSON file.

# Project URL

https://roadmap.sh/projects/task-tracker

## Setup

    git clone <your-repo-url>
    cd task-tracker
    npm install

## Usage

    node index.js <command>

## Commands

| Command                     | Description                 |
| --------------------------- | --------------------------- |
| `add <description>`         | Add a new task              |
| `list`                      | List all tasks              |
| `list-todo`                 | List todo tasks only        |
| `list-in-progress`          | List in-progress tasks only |
| `list-done`                 | List completed tasks only   |
| `update <id> <description>` | Update a task's description |
| `delete <id>`               | Delete a task               |
| `mark-in-progress <id>`     | Mark a task as in-progress  |
| `mark-done <id>`            | Mark a task as done         |

## Examples

    node index.js add "Buy milk"
    node index.js list
    node index.js mark-in-progress 1
    node index.js mark-done 1
    node index.js update 2 "Buy milk and eggs"
    node index.js delete 3

## Data

Tasks are stored in `tasks.json` in the project root. Do not edit this file manually.
